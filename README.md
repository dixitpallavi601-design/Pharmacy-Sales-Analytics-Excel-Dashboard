# 🏥 Pharmacy Sales Analytics Dashboard

## 📌 Project Overview

This project presents an interactive Pharmacy Sales Analytics Dashboard built in Microsoft Excel. The dashboard helps analyze sales performance across products, branches, customer types, payment methods, and pharmacists through interactive visualizations and KPI cards.

---

## 🎯 Business Requirement

The objective was to create an interactive dashboard that enables stakeholders to monitor sales performance, identify trends, and support data-driven business decisions.

---

## 📊 Dashboard Features

- KPI Cards
- Monthly Net Sales Trend
- Top Products by Net Sales
- Branch-wise Net Sales
- Category-wise Net Sales
- Customer Type-wise Net Sales
- Payment Method Distribution
- Top Pharmacists by Net Sales
- Interactive Slicers

---

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- KPI Cards
- Slicers
- Data Visualization
- Dashboard Design

---

## 📈 Key Insights

- Medical Devices generated the highest revenue.
- BP Monitor and Glucometer were the top-performing products.
- Mumbai Branch recorded the highest sales.
- Walk-in customers contributed the highest revenue.
- Cash and UPI were the most preferred payment methods.
